# Сторонние данные

## Каталог кофемолок

`src/grinders/catalog.generated.ts` создан скриптом `scripts/import-coffeejson-gear.mjs`
из реестра оборудования **CoffeeJSON** — <https://github.com/coffeejson-org/coffeejson>
(`registries/gear.json`, коммит `b7a4c4c`).

Лицензия данных: **CC0 1.0 Universal** (общественное достояние), атрибуция не требуется;
источник указан для прозрачности. Идентификаторы (`id`) совпадают с реестром,
чтобы рецепты можно было обменивать с другими приложениями формата CoffeeJSON.

В реестре нет шкал настроек кофемолок и перевода между ними — спецификация CoffeeJSON
сознательно такой конверсии не определяет. BrewMate тоже не подставляет «усреднённые» числа:
соответствие уровней крупности настройкам задаёт сам пользователь (экран «Моя кофемолка»).

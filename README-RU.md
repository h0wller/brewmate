# BrewMate Agent Starter

Стартовый комплект конфигурации OpenCode для проекта BrewMate. Он добавляет четыре роли, три навыка, правила проекта и Context7 MCP. Это конфигурация для проверки и адаптации, не автономный деплой.

## Состав
- `opencode.json` — подключение Context7 MCP.
- `AGENTS.md` — постоянные правила разработки BrewMate.
- `.opencode/agents/` — архитектор, frontend, backend, судья.
- `.agents/skills/` — рабочий процесс, ревью, безопасность Supabase.
- `Install-BrewMateAgents.ps1` — безопасное копирование файлов в корень репозитория с резервной копией совпадающих файлов.

## Рекомендуемый бюджет
Начни с одной подписки, которую OpenCode официально поддерживает через OAuth. OpenCode документирует вход через ChatGPT Plus/Pro; Claude Pro/Max через сторонние плагины в OpenCode использовать не следует, поскольку Anthropic запрещает этот сценарий. Уточняй доступность и способ оплаты в своём регионе до покупки. Не запускай сразу несколько платных подписок.

## Установка на Windows
1. Установи Node.js LTS и Git for Windows. Перезапусти терминал.
2. Установи OpenCode по текущей официальной инструкции: https://opencode.ai/docs/ (для npm обычно `npm install -g opencode-ai`; если официальный сайт уже предлагает другой стабильный пакет, следуй актуальной инструкции).
3. Распакуй архив в отдельную папку.
4. Открой PowerShell и запусти:
   `.\Install-BrewMateAgents.ps1 -ProjectPath "C:\путь\к\BrewMate"`
5. Перейди в проект:
   `cd "C:\путь\к\BrewMate"`
   `opencode`
6. В интерфейсе OpenCode выполни `/connect`, выбери OpenAI и вариант входа через ChatGPT Plus/Pro, если он доступен в твоём аккаунте. Затем `/models` и выбери доступную модель. Не вставляй пароль аккаунта в терминал.
7. Проверь Context7:
   `opencode mcp list`
   Если требуется OAuth, выполни `/mcps` в TUI и пройди авторизацию. Можно также выполнить `npx ctx7 setup --opencode`.
8. Проверь роли: `opencode agent list`. Если агентный список не обновился, перезапусти OpenCode.
9. Проверь проект обычными командами:
   `npm run lint`
   `npm test`
   `npm run build`

## Дополнительные навыки
- UI UX Pro Max (опционально):
  `npx ui-ux-pro-max-cli init --ai opencode`
- Context7 CLI/skills (альтернатива ручной настройке MCP):
  `npx ctx7 setup --opencode`
- Superpowers для OpenCode — устанавливай по актуальной инструкции репозитория; формат конфигурации различается между major-версиями OpenCode: https://github.com/obra/superpowers

Не ставь все инструменты одновременно. Сначала проверь основной цикл на одной задаче.

## Первый тест
В OpenCode попроси:
«Используй архитектора для read-only анализа задачи: проверь существующие тесты и структуру каппинга SCA/CoE, предложи один конкретный bugfix с критериями приёмки. Не редактируй файлы».
Затем попроси исполнителя реализовать согласованную небольшую задачу и судью независимо проверить diff.

## Безопасность
- Проверь `git status --short` перед установкой и до/после каждой задачи.
- Скрипт создаёт `.backup-agent-starter-<timestamp>` в проекте, если перезаписывает существующие файлы.
- Не давай агентам доступ к production secrets, не разрешай `git push`, деплой или production-миграции без ручного подтверждения.
- Проверяй установленные skills/plugins перед запуском: они исполняют инструкции и иногда команды.

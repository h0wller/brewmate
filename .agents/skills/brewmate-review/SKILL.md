# BrewMate review protocol

- Сначала изучи исходную задачу и критерии приёмки.
- Прочитай `git diff --check`, `git diff` и связанные тесты.
- Проверяй только изменённые строки и связанные риски, но прослеживай вызовы в обе стороны.
- Приоритизируй реальные дефекты над стилевыми предпочтениями.
- Проверяй ошибки, пустые значения, границы диапазонов, повторные вызовы, отмену/тайм-ауты и некорректный ввод.
- При изменениях данных проверяй совместимость старых данных и импорт/экспорт.
- При изменениях Supabase проверь отсутствие секретов в клиенте, корректность авторизации и отсутствие обхода RLS.
- При изменениях UI проверь мобильный экран, клавиатурную доступность, фокус, пустые и ошибочные состояния.
- Не вноси правки. Выдай замечания с приоритетом, путём/строкой, сценарием воспроизведения и ожидаемым исправлением.
- Не называй тесты пройденными, если не запускал их сам.

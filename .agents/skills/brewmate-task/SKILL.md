# BrewMate task workflow

1. Прочитай `AGENTS.md`, `package.json`, README и релевантные модули.
2. Проверь `git status --short`; не трогай незакоммиченные изменения пользователя.
3. Сформулируй критерии приёмки до редактирования.
4. Найди существующий паттерн и выбери минимальный diff.
5. Для задачи, затрагивающей несколько областей, сначала вызови архитектора и согласуй контракты.
6. Разделяй независимые UI и data/backend задачи только если границы файлов и API понятны. Не запускай параллельные изменения в одних файлах.
7. Реализуй и добавь/обнови тесты.
8. Запусти `npm run lint`, `npm test`, `npm run build` (или объясни, почему какая-то команда не применима).
9. Попроси `judge` проверить diff независимо.
10. Устрани блокирующие и серьёзные замечания, повтори проверки.
11. В отчёте укажи изменения, команды, фактические результаты и остаточные риски.

Не считать вывод модели доказательством. Доказательства — код, тесты, diff и наблюдаемое поведение.
